# daxtar2

Personal homepage repository for [@daxtar2](https://github.com/daxtar2), adapted from [academic-homepage](https://github.com/luost26/academic-homepage).

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000/daxtar2/`.

## Deploy

Push to the default branch and GitHub Actions will build and deploy the site to GitHub Pages.

Current scope:

- Home page only
- Blog / publications / other tabs can be added later
